# Передача проекта

Всё, что нужно, чтобы приложение жило у вас и ни от кого не зависело.
По шагам, сверху вниз. Терминал не нужен нигде.

---

## 1. Забрать проект себе

Заведите аккаунт на **github.com**, если его нет, и пришлите свой ник.
Вам передадут репозиторий целиком, со всей историей правок.
После передачи проект ваш: прежний владелец теряет к нему доступ.

## 2. Включить адрес приложения

В своём репозитории: **Settings → Pages → Branch: main → Save**.
Через пару минут приложение открывается по адресу:

`https://ваш-ник.github.io/mission-control-english/`

Этот адрес постоянный. Его и даёте семье.

## 3. Настроить себе рабочее место

Поставьте **GitHub Desktop** (github.com/apps/desktop) — два клика, без терминала.
Внутри: **Clone repository** → выбираете `mission-control-english`.
Папка появится у вас на компьютере.

Дальше цикл работы всегда один:

1. открыли папку в Codex, попросили что-то поправить
2. проверили — открыть `index.html` двойным кликом
3. в GitHub Desktop: строчка что сделали → **Commit** → **Push origin**
4. через минуту по адресу новая версия

## Синхронизация между устройствами

Пока файл `config.js` пустой, приложение работает на одном устройстве:
прогресс хранится в браузере. Для занятий этого достаточно.

Если нужно, чтобы **ребёнок занимался на своём устройстве, а родитель
видел статистику со своего телефона** — заведите базу. Это бесплатно
и занимает минут пять.

### Что сделать

**1.** На **supabase.com** → New project.
Имя любое, пароль базы придумайте и забудьте — он не понадобится.

**2.** Когда проект создастся: слева **SQL Editor** → вставьте и нажмите Run:

```sql
create table stations (
  id text primary key,
  data jsonb,
  updated_at timestamptz default now()
);
alter table stations enable row level security;
create policy "app" on stations for all to anon using (true) with check (true);
```

**3.** Слева **Settings → API**. Оттуда нужны две строки:
**Project URL** и ключ **anon public**.

**4.** Откройте `config.js` и впишите их:

```js
const CFG = {
  url:  'https://ваш-проект.supabase.co',
  anon: 'eyJhbGci...'
};
```

**5.** Commit → Push. Готово.

### Как это выглядит для семьи

При первом входе приложение просит **код станции** — короткое слово,
например `DENIS2026`. Ребёнок вводит его на своём устройстве,
родитель вводит **тот же код** у себя. Дальше всё общее:
ребёнок отвечает на задания — родитель через минуту видит обновление.

В верхней строке горит зелёное «связь с Землёй», когда синхронизация работает.

### Про ключи — важно

Ключ **anon public** для того и создан, чтобы лежать в коде страницы.
Это не утечка.

Ключ **service_role** лежит в Supabase рядом и выглядит похоже.
**Его в `config.js` вставлять нельзя никогда** — он даёт полный доступ к базе.

Правило доступа из шага 2 простое: кто знает код станции, тот видит её данные.
Для семейного тренажёра этого достаточно. Если нужно строже — нужен вход по паролю,
это уже отдельная работа.

## Две вещи, на которых легко споткнуться

**В `bank.js` первый вариант ответа всегда правильный.**
Перемешивание происходит на экране. Переставите — сломается проверка.

**Codex склонен разгоняться.** Попросишь дописать задания — предложит поднять
сервер, базу и сторонний хостинг. Всё нужное уже сделано; держите его в рамках
одной задачи и просите показывать план до правки файлов.
