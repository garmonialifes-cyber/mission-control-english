# Mission Control English — проект для Дениса (9 лет)

Тренажёр английского по американской программе **Grade 3–4 (Common Core ELA)**.
Ребёнок — мальчик 9 лет, активно читает по-английски, увлекается космосом.

## Главная идея

Не тесты, а центр управления полётом. Денис — стажёр на станции.
Пробел в знаниях = неисправность в отсеке. Закрыл — летим дальше.
Приложение само находит дыру и каждый день даёт задания именно в неё.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | всё приложение: стили, экраны, движок заданий. Автономный, открывается двойным кликом |
| `bank.js` | банк заданий: `SKILLS`, `PLANETS`, `BANK`. Только данные, логики нет |
| `config.js` | адрес и ключ базы для синхронизации. Пусто = работа на одном устройстве |
| `ПЕРЕДАЧА.md` | инструкция владельцу: хостинг, база, цикл работы |

Прогресс хранится в `localStorage` под ключом `mce_denis_v1`.

## Девять навыков (отсеков)

`s3` хвостик -s · `past` неправильные глаголы · `cont` am/is/are + ing ·
`prep` предлоги · `plur` множественное число · `comp` сравнение ·
`art` артикли · `read` чтение с пониманием · `voc` космический словарь

Сейчас по 8 заданий на навык = 72.

## Формат задания (bank.js)

```js
{
  q:'He ___ to the space station every morning.',   // вопрос
  o:['goes','go','going','gone'],                   // ВАЖНО: первый вариант всегда верный, на экране перемешиваются
  why:'«He» — это один человек. У глагола рядом с he / she / it вырастает хвостик -s.',
  rule:'he / she / it + глагол + s',
  ex:'She flies. It works. He goes.',
  again:'Проверь себя так: если можешь заменить слово на «он / она / оно» — ставь -s.',
  up:{ q:'She ___ (fly) the shuttle.', a:'flies' }   // мини-проверка после разбора
}
```

## Правила контента — соблюдать при любом добавлении

1. **Объяснение — не «неверно», а разбор.** Четыре слоя: `why` (что именно не так) → `rule` (правило коротко) → `ex` (как звучит) → `up` (сразу закрепить).
2. **`again` заходит с ДРУГОЙ стороны**, а не повторяет `why` другими словами. Оно показывается, если ребёнок ошибся в мини-проверке дважды.
3. **Язык объяснений — русский, живой, детский, но не сюсюкающий.** Образы («хвостик», «антенна», «лесенка времени»), а не грамматические термины.
4. **Вся фактура — про космос и настоящая.** Никаких выдуманных цифр и фактов. Тексты для чтения — реальные (Perseverance, Jezero Crater, Уэбб, МКС).
5. **Уровень строго Grade 3–4.** Не усложнять лексику ради красоты.
6. **Ошибка — это неисправность, которую чинят, а не провал.** Ни «жизней», ни таймера, ни штрафов в текстах.

## Дизайн — не трогать без причины

Пульт ЦУПа, а не детское приложение с шариками.
Тёмный фон `#070B18`, янтарный акцент `#FFB454`, зелёный «исправен» `#4ADE80`, красный «повреждение» `#F2555A`.
Шрифты: Chakra Petch (приборные заголовки), Source Sans 3 (текст заданий), IBM Plex Mono (данные).
Прямые углы, тонкие рамки, статус кодируется полосой слева. Тема одна — тёмная, намеренно.

## Синхронизация

Если `config.js` заполнен, приложение при первом входе просит **код станции**
и держит весь прогресс в таблице `stations` (Supabase, поле `data` — весь объект
состояния целиком). Опрос раз в 12 секунд, запись через 0.9 секунды после изменения.

Поля `pin` и `station` в облако НЕ уходят — они у каждого устройства свои.
Последняя запись побеждает: одновременная правка призов родителем и ответ ребёнка
могут затереть друг друга. Для семьи это приемлемо; если понадобится строже —
писать отдельные документы на каждую часть состояния, а не один общий.

Если `config.js` пуст, весь этот слой молчит и приложение работает на localStorage.
Ломать это поведение нельзя: оно же запасной путь, когда база недоступна.
