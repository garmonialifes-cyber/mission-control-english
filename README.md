# Mission Control English

Тренажёр английского языка для ребёнка 9 лет по американской программе
**Grade 3–4 (Common Core ELA)**. Тема-обёртка — космос.

Приложение само находит пробелы в знаниях и каждый день даёт задания
именно туда, где дыра. Каждая ошибка разбирается: что не так, почему,
как правильно — и сразу мини-проверка на то же правило.

---

## Как открыть

Распакуйте архив и откройте **`index.html`** двойным кликом.
Интернет нужен только на первую загрузку (подтягиваются шрифты).

Ничего устанавливать не надо. Работает на ноутбуке и на планшете.

**Первый вход** — проверка систем, 18 вопросов, около 20 минут.
Дальше приложение каждый день само выбирает, что тренировать.

**Прогресс** сохраняется в браузере на этом устройстве. Если открыть
в другом браузере — начнётся с нуля. Сброс: вкладка «Для мамы», кнопка внизу.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение целиком: экраны, логика, оформление |
| `bank.js` | банк из 72 заданий по 9 навыкам |
| `AGENTS.md` | техническое описание для доработки |

---

## Как дорабатывать

Откройте папку в **Codex** (Open folder) или в **Claude Code**.
Файл `AGENTS.md` прочитается автоматически — там формат заданий,
правила стиля объяснений и палитра. После этого достаточно писать
задачи обычными словами:

> добавь 10 заданий в отсек про артикли
> сделай тексты для чтения длиннее
> добавь десятый отсек — вопросы Wh-questions

---

## Что стоит доделать дальше

- **Банк конечный.** 72 задания — после полного круга они пойдут по второму разу.
  Следующий шаг: генерация новых заданий, чтобы не кончались.
- Озвучка и проверка произношения вслух.
- Больше текстов для чтения.
